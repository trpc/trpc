# Next.js App Router + tRPC

This example shows how you can make a typed query using a minimal implementation of tRPC with the Next.js App Router, following the [App Router setup guide](https://trpc.io/docs/client/nextjs/app-router-setup).

## Setup

```bash
npx create-next-app --example https://github.com/trpc/trpc --example-path examples/next-minimal-app-router trpc-minimal-app-router
cd trpc-minimal-app-router
npm i
npm run dev
```

## Development

### Start project

```bash
npm run dev        # starts next.js
```
