# The v10 docs

A copy of the [v10 docs](../../../../v11/www/versioned_docs/version-10.x), which [trpc.io](https://trpc.io/docs/v10) renders. The site serves it at `/v10/docs`, for v10 users while v12 is experimental.

Don't edit these files: `www/build/old-docs-copy.ts` writes them. Change the docs in `v11/www/versioned_docs/version-10.x`, then run `pnpm --filter @trpc12/www old-docs:copy`.
