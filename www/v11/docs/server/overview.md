This section covers everything you need to set up and configure your tRPC backend. You'll learn how to define [routers](./routers.md) and [procedures](./procedures.md), set up [context](./context.md), add [input validation](./validators.md), and use [middlewares](./middlewares.md) to extend your API.

Once your API is defined, you can host it using one of the available [adapters](./adapters.md) for platforms like Express, Fastify, Next.js, AWS Lambda, and more.
