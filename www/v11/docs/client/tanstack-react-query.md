This is the recommended way to use tRPC with React and TanStack Query. It provides factories for common TanStack React Query interfaces like `QueryKeys`, `QueryOptions`, and `MutationOptions`, giving you a more TanStack Query-native experience.

If you're starting a new project, we recommend using this integration over the [classic React Query integration](./react.md). Read the [announcement post](/blog/introducing-tanstack-react-query-client) for more information about this change.

Head to the [Setup](./tanstack-react-query/setup.md) guide to get started.
