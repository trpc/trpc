This is the recommended way to use tRPC with React and TanStack Query. It provides factories for common TanStack React Query interfaces like `QueryKeys`, `QueryOptions`, and `MutationOptions`, giving you a more TanStack Query-native experience.

If you're starting a new project, use this integration rather than the [classic React Query integration](/docs/client/react), which only gets bug fixes and will be removed in the next major version of tRPC. To move an existing project, follow the [migration guide](/docs/client/tanstack-react-query/migrating). Read the [announcement post](/blog/introducing-tanstack-react-query-client) for more information about this change.

Head to the [Setup](/docs/client/tanstack-react-query/setup) guide to get started.
