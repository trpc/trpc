# Lint rules taken from the vendored repos (human asked)

- Human, 2026-10-18: "Any other lint rules to port from vendor-src? Make sure we ignore their own vendored projects BTW, almost recursive".
- (agent) Every vendored repo now ignores `.repos/**` in `../vendor-src.json`. `raf-query` vendors TanStack Query, TanStack Router and Effect 4.0.1, which was 18,514 of the 23,401 files under `.repos/`; it was pruned by hand, since syncing it would move its pinned SHA. Nothing below comes from those nested trees.
- (agent) Measured every rule in Effect's `packages/tools/oxc` (its oxlint config and its `effect/*` plugin), raf-query's `.oxlintrc.json` and plugins (`anti-slop`, `nkzw`, `workspace`), and oRPC's `eslint.config.js` against this workspace, per `tooling/oxlint-plugin/AGENTS.md`. Adopted, each with its hits fixed:
  - `categories: { correctness: 'error' }` (Effect and raf-query): warnings don't fail `pnpm check`, so `test.only` passed. No other hits.
  - `anti-slop-effect/no-manual-effect-error-tag` (raf-query, from upstream at our pin): `no-manual-tag-comparison` skips `_tag` comparisons inside `Effect.catch`/`catchAll`/`catchIf`, leaving them to this rule, so "recover with `catchReason`" wasn't enforced. No hits.
  - From Effect's config: `typescript/consistent-type-imports` (a value import used only as a type is a runtime edge `import/no-cycle` counts; 18 hits, two of them `import()` type annotations), `typescript/no-import-type-side-effects` (two hits, after the autofix above), `typescript/no-unnecessary-type-constraint`, `typescript/no-useless-empty-export`, `import/no-duplicates` (three hits; off in `www/samples/**`, whose `#region`s each import what they show), `import/no-self-import`, `no-unneeded-ternary`, `no-useless-concat`, `no-useless-constructor`, `no-var`, `unicorn/no-accessor-recursion`, `unicorn/prefer-array-flat-map` (one hit, the docs build's experiment check).
  - From raf-query's: `preserve-caught-error`, `no-empty`, `prefer-const` (with `ignoreReadBeforeAssign`, for `interop/link.ts`'s `teardown`), and `no-restricted-imports` on `onTestFinished`, the way around `vitest/no-hooks` (the framework-matrix example's Solid, Svelte and Vue tests now `await using` the server and `using` the unmount). `no-empty` had three hits: empty `catch` blocks, now commented.
  - From oRPC's: `guard-for-in`. Its two hits were real: danSON's serializer copied keys inherited from a polluted `Object.prototype` onto the wire (or threw, if the key was read-only). Both serializers now walk `Object.keys`/`Object.values`; `serializer/danson/danson.test.ts` covers it.
- (agent) Tried, and not adopted:
  - `typescript/no-unnecessary-type-assertion` (Effect): 57 hits, but the autofix removed casts TypeScript needs (to an all-optional type; before `res.json<T>()`, whose `T` came from the cast) and casts that satisfy `typescript/no-base-to-string`. Without `eslint-disable`, each of those would need a rewrite.
  - `array-callback-return` (raf-query): it reads `Effect.map(…)` as `Array.prototype.map`, and void `Effect.map`/`Stream.map` callbacks are normal here.
  - `import/no-empty-named-blocks` (Effect): its fix deletes `import type {} from '@trpc12/trpc/internal'`, which the entry points need for declaration emit.
  - Effect's plugin: `no-unused-internal` needs TypeScript's JS API, which TypeScript 7 doesn't have; run against 6.0, all 156 hits were `@internal` types in public signatures, which only matters with `stripInternal`. `no-import-from-barrel-package` and `no-bigint-literals` are about Effect's own packages. `no-js-extension-imports` and `no-opaque-instance-fields` had no hits and would mean vendoring a second plugin.
  - raf-query's style and React-app rules: `curly` (964 hits), `typescript/array-type` (502), `anti-slop/require-safety-comment-for-type-assertion` (818), the other `anti-slop/*` rules (`unknown` parameters and returns, `typeof`, options objects; a library does all of these on purpose), `nkzw/no-instanceof` (93), `perfectionist`, `eslint/no-underscore-dangle` (`_tag`), `anti-slop-effect/no-service-constructor-imports` (reads any `make*` import as a service constructor), and the hook rules, which raf-query turns off for its own library bindings. `workspace/inline-jsx-callback` had no hits; it's untyped, and our one JSX example is small.
  - Type-aware extras with few hits: `switch-exhaustiveness-check` flags `string` switches over proxy method names, and `only-throw-error` flags exactly the framework rethrows [`no-throw-in-effect.md`](./no-throw-in-effect.md) allows.
- Why: the vendored repos' rules are already measured against Effect-style TypeScript, and each adopted one either found a bug or costs nothing to keep.
- Lost: the cleanup `no-unnecessary-type-assertion` would have done (about 50 casts that do nothing).
- Open: oRPC's runtime-portability bans, which depend on which runtimes v12 supports, and no decision says yet. `AbortSignal.any` (missing in React Native) is called in `httpLink`'s transport and the OpenAPI link. `decodeURIComponent` throws on malformed input; its calls on request paths are guarded (`/trpc/%E0%A4%A` is a 400 in `createV11Handler` and the OpenAPI handler, a 404 in the v12 handler). The bans would need oRPC's `safeDecodeURIComponent`-style helpers.
- Lives in: `../vendor-src.json`, `AGENTS.md` (Vendored Source), `vite.config.ts` (`lint`), `tooling/oxlint-plugin/anti-slop/` (`no-manual-effect-error-tag` and `AGENTS.md`), `packages/trpc/src/transformer/danson/sync.ts` and `stream.ts`.
