# The OpenAPI document is shaped for generated clients such as Hey API (human asked)

- Human, 2026-10-19, on a comparison of `@trpc12/trpc/openapi` with [Hey API](https://heyapi.dev) (`@hey-api/openapi-ts`) that found five gaps and proposed a page on generating a client with it: "sure". Hey API reads OpenAPI and writes clients; it never writes a document. So the document is the interop line: when it's correct, every Hey API plugin (SDKs, zod/valibot, TanStack Query, MSW, other languages) works on a tRPC API, with no SDK codegen of our own.
- (agent) `experimental_generateContractFromOpenApi` follows `$ref`s to parameters, request bodies and responses, applies path-level parameters, and types header parameters ([`openapi-to-contract.md`](./openapi-to-contract.md)). Before, a GitHub-style spec lost those inputs and outputs.
- (agent) `experimental_generateOpenApi` takes `components.securitySchemes`, document-level `security` and `tags`, with OpenAPI's own field names. Hey API's `auth` callback and docs UIs' login forms need declared schemes. Before, `route.spec` could add `security` to an operation, but the scheme it named didn't exist. `components.schemas` is passed through too, and generated schemas win on a name clash.
- (agent) A body with a file anywhere in it (`format: binary`, `contentEncoding: binary`, or a non-JSON, non-text `contentMediaType`, through `$ref`s) is documented as `multipart/form-data` only: JSON can't carry it, and Hey API picks its form serializer from the media type. zod's `z.instanceof(File)` and `z.instanceof(Blob)` inputs become `format: binary` through zod's `unrepresentable` hook; they were `{}`. A single `Blob` for an array field is coerced into an array of one, as a single string already was, since form serializers send one item as one field. The `rpc` target is unchanged; RPC sends files in frames.
- (agent) The `default` error response is `TrpcUntypedError` (`defined: false`, any `code`) or a typed error whose `code` is an `enum` of the built-in server codes that the operation doesn't document. Before, it was `TrpcError` with `defined: boolean` and `code: string`, which overlapped every documented error, so Hey API's error union never narrowed. Checked against Hey API 0.99.0 output: `error.defined && error.code === 'NOT_FOUND'` types `error.data`. Open: a typed error with a custom code that the document doesn't list (a runtime-only document of a procedure without `.errors()` that returns one) falls outside the schema. `.errors()` or `experimental_generateOpenApiFromTypes` documents it. The component was renamed from `TrpcError`; the API is experimental.
- (agent) zod `Date`s, which zod can't represent in JSON Schema, are `{ type: 'string', format: 'date-time' }` as outputs, and as inputs only under `z.coerce.date()`, through the same `unrepresentable` hook. REST and RPC both send a `Date` as its ISO string. A plain `z.date()` input stays `{}`, since a JSON or form client can't satisfy it, and `bigint` stays `{}`. Outputs match the types generator, and Hey API's `transformers.dates` turns the strings back into `Date`s. Effect's `Schema.Date` is `{ type: 'string' }` without a `format`, as Effect writes it; that is left to Effect.
- (agent) `www/docs/openapi/hey-api.md` compiles against a real Hey API SDK: `www/samples/docs/src/api/` is generated from `src/rest.ts` (`pnpm --filter @samples/docs generate:api`) and committed, so a document change that breaks narrowing, auth, files or dates fails the docs build. Hey API 0.99.0 needs TypeScript's JavaScript API, which TypeScript 7 lacks, though its peer range allows 7. So the samples install it for types only, and the script runs it through `pnpm dlx` with TypeScript 6.
- (agent) The SSE `done` frame keeps its empty `data:` line, so Hey API yields a trailing `''` and an `error` frame's body as items; the page tells them apart with `onSseEvent`. Without data, `EventSource` drops the event and keeps reconnecting, and tRPC's clients stop on `done` ([`fetch-sse.md`](./fetch-sse.md)). A non-JSON `data` value or a comment would still be yielded, or would end the stream without saying it ended, so no wire change was cheap.
- Lost: SDK, HTTP-client, validator and mock generation of our own; Hey API covers them.
