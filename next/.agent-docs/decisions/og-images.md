# A social card per page, drawn by the site on request (human asked)

- Human, 2026-10-17: "Also steal the og images from v12 but modernize them / I know it had a bunch of custom og based on pages". The cards meant are trpc.io's (the v11 site's), from the `@vercel/og` functions in `v11/www/og-image`: one for the landing page and one per docs page with its title, description and URL.
- (agent) Since 2026-11-01 the cards are #7771's, which `main`'s trpc.io draws too, replacing v12's build-time renderer (`og-image.ts`) when the site moved to the root ([`one-workspace.md`](./one-workspace.md)). `www/src/routes/og.$.ts` draws `/og/<page path>.png` on request (`/` is `/og/index.png`) with satori and `@resvg/resvg-wasm` (`www/src/og/render.ts`); the build makes only the list of cards (`www/build/og-cards.ts`, `virtual:og-cards`), and a path without a card is a 404. `pageHead` points `og:image` and `twitter:image` at it, with `twitter:card` `summary_large_image`.
- (agent) The designs are trpc.io's `og-image` service's, as #7771 kept them: the home card (logo, tagline, subtitle, the GitHub stars and the weekly npm downloads, `@trpc/server`'s plus `@trpc12/trpc`'s where v12 is offered ([`npm-downloads.md`](./npm-downloads.md))), a post's (date, title, description, reading time, each author's avatar, name and title) and a docs page's (logo, title, description and URL), which v12's pages use too.
- (agent) What changes after a deploy (the stars, the downloads, the authors' avatars) is fetched when a card is drawn (`www/src/og/live.ts`); a fetch that fails leaves its part out, and the card is cached briefly so the next request tries again.
- Why: links shared to the docs show what the page is about, as trpc.io's do, with one renderer for both branches, and no PNGs in the build.
- Lost: v12's modernized design (left-aligned, brand glow, a version pill, an install command on the home card), and cards as static files: each is a function call until the CDN caches it.
- Lives in: `www/src/routes/og.$.ts`, `www/src/og/` (`card.ts`, `render.ts`, `live.ts`, `pattern.svg`), `www/build/og-cards.ts`, `www/src/seo.ts` (`ogImagePath`, `pageHead`), `www/vite.config.ts`.
