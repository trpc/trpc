# A social card per page, rendered at build time (human asked)

- Human, 2026-10-17: "Also steal the og images from v12 but modernize them / I know it had a bunch of custom og based on pages". The cards meant are trpc.io's (the v11 site's), from the `@vercel/og` functions in `v11/www/og-image`: one for the landing page and one per docs page with its title, description and URL.
- (agent) `www/build/og-image.ts` renders every card in the build, with satori (layout to SVG) and resvg (SVG to PNG), into `og/<page path>.png` (`/` is `og/index.png`, `/v12/docs/server/procedures` is `og/v12/docs/server/procedures.png`, `/docs/quickstart` is `og/docs/quickstart.png`). `pageHead` points `og:image` and `twitter:image` at it, with `twitter:card` `summary_large_image`. The dev server renders a card when it's asked for.
- (agent) The design keeps trpc.io's: dark, its logo pattern (`build/og/pattern.svg`, recolored to the brand blue and faded), Inter, the page's title, description and URL, and the landing card's "Move Fast and Break Nothing." / "End-to-end typesafe APIs made easy.". It's modernized as 1200×630, left-aligned, with a brand glow, the section above the title, a version pill ("v12 · experimental", "v11 · stable"), the URL in monospace and an install command on the landing card. A v11 card shows the page's trpc.io URL, its canonical one.
- (agent) No network at build time: fonts come from `@fontsource`, and the landing card drops the GitHub stars and npm downloads, which would make the build depend on two APIs and the cards change on every deploy.
- Why: links shared to the docs show what the page is about, as trpc.io's do, without a server or an image service: the site stays static files.
- Lost: the live star and download counts; emoji in titles (the fonts carry Latin only, so `plainText` drops them); about 11 seconds and 32 MB of PNGs per build (139 cards).
- Open: caching the cards between builds, like the twoslash blocks, if the build time matters.
- Lives in: `next/www/build/og-image.ts`, `next/www/build/og/pattern.svg`, `next/www/src/seo.ts` (`ogImagePath`, `pageHead`), `next/www/vite.config.ts`.
