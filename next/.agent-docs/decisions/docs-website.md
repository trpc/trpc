# A docs website in `next/www`, rendered from `next/docs` (human asked)

- Human, 2026-10-17: "build a website in the `next/www` folder for v12 … borrow ideas freely and steal stuff from raf-query (also my package); it uses shadcn nicely and has good twoslash stuff that is cached etc. … ignore v11 linking etc for now". This supersedes Q21.5's "We won't build the website yet" ([`repo-and-tooling.md`](./repo-and-tooling.md)).
- (agent) The pages are plain Markdown in `next/www/docs/` (in `next/docs/` until 2026-10-20, [`docs-in-www.md`](./docs-in-www.md)), one short page per topic in a folder per sidebar section (`server/`, `middleware/`, `client/`, `subscriptions/`, `openapi/`, `adapters/`, `integrations/`, `migrations/`). Frontmatter (`title`, `description`, `section`, `order`) is required; `section` must be one of `sections` in `www/src/site.ts`, and an optional `parent` nests the page under another page of its section ([`docs-nav-levels.md`](./docs-nav-levels.md)).
- (agent) The site is raf-query's: TanStack Start, prerendered to static files, Tailwind 4 and shadcn (base-ui) components from `shared/ui` ([`shadcn-lib-and-branding.md`](./shadcn-lib-and-branding.md)), Shiki with `@shikijs/twoslash`, a disk cache of compiled blocks, `llms.txt`, `llms-full.txt` and a `.md` twin of every page (also on `Accept: text/markdown`). The build pipeline is Effect, under `www/build/`, with its tests in the root `node` project.
- (agent) A `ts twoslash` block compiles in the `www/samples/docs` app: its imports resolve against the workspace packages, `./server.ts` and `./client.ts` are the app's shared router and client, and `// @filename:` defines more files (a block's file replaces the app's file of the same name). A type error the block doesn't declare with `// @errors:` fails the build, so examples can't drift from the API. The app installs the platforms the pages show (Workers types, Nest, Next.js, React, Bun, TanStack DB, the AI SDK, Better Auth), so every block that can compile does; the few left plain `ts` need something it doesn't install (Firebase, Deno, `@ai-sdk/react`, `@effect/opentelemetry`, Express or Fastify), or are fragments of a file. The v11 docs' blocks compile in `www/samples/v11` instead, against tRPC v11 from npm ([`old-docs-copy.md`](./old-docs-copy.md)).
- (agent) Links between pages are relative `.md` links, so they work on GitHub too. The build rewrites them to site URLs and fails on a missing page or heading; links outside `www/docs/` go to the file on GitHub (`site.sourceUrl`, which `contentPath: 'www/docs'` places the folder under).
- (agent) Vite's preview server, which TanStack Start's prerender starts and fetches in the build's process, binds `127.0.0.1` (`preview.host` in `www/vite.config.ts`, so `pnpm start` too). On `localhost` it bound `::1` only, and Node's fetch tries `::1` with a 250ms timer per address: a page render holding the event loop past it ended the attempt (`ETIMEDOUT ::1`), the fallback hit `ECONNREFUSED 127.0.0.1`, and the unhandled rejection failed half the `www` CI runs. Considered: `prerender.retryCount` (retries the symptom), `net.setDefaultAutoSelectFamily(false)` in the config (process-wide).
- (agent) The cache lives in `www/node_modules/.cache/twoslash`, one file per block, keyed by the block, its compiler options, the app files it read and the lockfile. CI restores it in the `www` job of `next.yml`.
- Why: compiled examples are the only docs that stay right through a rewrite this large; keeping Markdown as the source keeps the agents' workflow ("update docs with each change") as it was.
- Lost: MDX and React components inside pages (a page is Markdown only); typechecking the blocks that stay plain `ts`; a generated API reference.
- (agent) Since 2026-10-17 the site also serves a copy of the v11 docs, with a version switcher and a banner on every page linking each page to its counterpart ([`old-docs-copy.md`](./old-docs-copy.md)). Since 2026-10-18 the v11 copy is at `/docs`, what the site opens with, and these pages are at `/v12/docs` ([`docs-v11-by-default.md`](./docs-v11-by-default.md)).
- (agent) Every page has a social card (`og:image`), rendered in the build ([`og-images.md`](./og-images.md)).
- (agent) The docs pages credit the projects v12 builds on: Zodios, trpc-openapi, ts-rest and oRPC ([`docs-credits.md`](./docs-credits.md)).
- Open: the Vercel project and the domain (`site.url` is `https://v12.trpc.io`, unclaimed); the repo side is ready ([`docs-website-on-vercel.md`](./docs-website-on-vercel.md)); full-text search (the dialog matches titles, descriptions and headings).
- Lives in: `next/www/` (`build/`, `src/`, `samples/`), `next/www/docs/`, `next/vite.config.ts` (`www/build` tests), `.github/workflows/next.yml` (`www`).
