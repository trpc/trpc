# Docs pages that wait for review are hidden from the site and search engines (human)

- Human, 2026-10-18: "ok so i want to start trimming stuff down from what we've done now and hide certain parts that we've just "vibe ported" from orpc etc on the site … it's overwhelming to review all of this stuff and its overwhelming to know what to use and not … can you prompt me on things to hide? i also want those things to be hidden from search engines".
- Human, 2026-10-18 (decision round, what hidden means): "B": unlisted, plus an experiment that shows the hidden pages.
- (agent) `hidden: true` in a page's frontmatter hides it. The page is still built and served at its URL, with a "Hidden page" note at its top, but the sidebar, site search, prev/next links, "Pages under" lists, the breadcrumb's section link, the sitemap, `llms.txt` and `llms-full.txt` leave it out, and the version switcher doesn't land on it from v11. It has `<meta name="robots" content="noindex">`, and on Vercel it and its `.md` get `X-Robots-Tag: noindex` (`build/vercel-output.ts` reads the pages' robots meta). A home page feature card whose page is hidden isn't shown.
- (agent) The build fails when a listed page links to a hidden one or nests under it in the sidebar, so a hidden page can't be reached by browsing; hidden pages may link anywhere. Hiding a page means trimming what the listed pages say about it.
- (agent) The `hidden-docs` experiment (`?flags=hidden-docs`, in the header's Experiments menu) lists the hidden pages again in the sidebar, search and pagination, each marked with a crossed-out eye. Search engines and agents still get the trimmed site.
- Human, 2026-10-18 (decision round, OpenAPI): "A yes and it should be experimental_ too". The OpenAPI section's five pages are hidden, with its home card, and every value `@trpc12/trpc/openapi` exports is `experimental_` ([`openapi.md`](./openapi.md)). Listed pages no longer mention OpenAPI: the routers page's lazy-subtree prefixes and build-time contract, the errors and Effect pages' document entries, the files page's REST bodies, the extensions page's `route` merge example, and the entry-point and links tables.
- Human, 2026-10-18 (decision round, middleware): "a". Rate limiting, Locks and Durable calls are hidden; the middleware overview and Lifecycle hooks stay. `experimental_durableLink`'s row leaves the links table with them, and the retry link's rate-limit section no longer links to `rateLimit()`.
- Human, 2026-10-18 (decision round, adapters): "a". Firebase, Message ports and Raw sockets are hidden; AWS Lambda stays. Their rows leave the adapters, links and entry-point tables, the home page's "Every runtime" card stops naming them, and listed pages that named `experimental_messagePortLink` or `experimental_socketLink` next to `wsLink` name `wsLink` alone.
- Human, 2026-10-18 (decision round, Cloudflare): "A - group all of that under one thing (i think it's all cloudflare stuff?)". The Durable Objects page becomes one hidden Cloudflare page (`adapters/cloudflare.md`) for everything `@trpc12/trpc/cloudflare` exports, and takes in the Durable Object recipe from Publisher backends. Locks and Workers Traces were on it already; the lock and tracing pages' pointers to it go. `experimental_hibernatingPublisher` and `experimental_connectionToken` join the entry point's other `experimental_` values ([`cloudflare-hibernation.md`](./cloudflare-hibernation.md)). The home page's "Every runtime" card stops naming Durable Objects.
- Human, 2026-10-18 (decision round, TanStack Query frameworks): "A". The Preact, Vue, Solid, Svelte, Angular and Lit pages are hidden; React and the shared TanStack Query pages stay. The framework and package tables list React alone, and the home page's "Framework integrations" card names React only.
- Human, 2026-10-18 (decision round, TanStack DB): "a". The TanStack DB page is hidden; Hydration and offline mutations stays.
- Why: the v12 docs grew a page for every oRPC parity row and every agent call, which is too much to review and makes it hard to tell what to use; hiding keeps the work (and its tests) while the site shows what's been reviewed.
- Lost: hidden features are invisible to readers who don't know the flag; their pages' links from listed pages, which go until a page is shown again.
- Open: reviewing each hidden page and dropping its `hidden: true`, with the links back.
