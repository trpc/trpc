# Docs pages that wait for review are hidden from the site and search engines (human)

- Human, 2026-10-18: "ok so i want to start trimming stuff down from what we've done now and hide certain parts that we've just "vibe ported" from orpc etc on the site … it's overwhelming to review all of this stuff and its overwhelming to know what to use and not … can you prompt me on things to hide? i also want those things to be hidden from search engines".
- Human, 2026-10-18 (decision round, what hidden means): "B": unlisted, plus an experiment that shows the hidden pages.
- (agent) `hidden: true` in a page's frontmatter hides it. The page is still built and served at its URL, with a "Hidden page" note at its top, but the sidebar, site search, prev/next links, "Pages under" lists, the breadcrumb's section link, the sitemap, `llms.txt` and `llms-full.txt` leave it out, and the version switcher doesn't land on it from v11. It has `<meta name="robots" content="noindex">`, and on Vercel it and its `.md` get `X-Robots-Tag: noindex` (`build/vercel-output.ts` reads the pages' robots meta). A home page feature card whose page is hidden isn't shown.
- (agent) The build fails when a listed page links to a hidden one or nests under it in the sidebar, so a hidden page can't be reached by browsing; hidden pages may link anywhere. Hiding a page means trimming what the listed pages say about it.
- (agent) The `hidden-docs` experiment (`?flags=hidden-docs`, in the header's Experiments menu) lists the hidden pages again in the sidebar, search and pagination, each marked with a crossed-out eye. Search engines and agents still get the trimmed site.
- Why: the v12 docs grew a page for every oRPC parity row and every agent call, which is too much to review and makes it hard to tell what to use; hiding keeps the work (and its tests) while the site shows what's been reviewed.
- Lost: hidden features are invisible to readers who don't know the flag; their pages' links from listed pages, which go until a page is shown again.
- Open: reviewing each hidden page and dropping its `hidden: true`, with the links back.
