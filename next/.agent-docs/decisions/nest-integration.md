# NestJS: `@trpc12/experimental-nest` implements contracts in controllers on the OpenAPI handler, as experimental (human)

- Answers the parity row "Nest.js integration: later, built on contracts" ([`../reference/orpc-parity.md`](../reference/orpc-parity.md)).
- Human, 2026-10-16 (decision round): "B". The shape below stays, and every value is experimental until the human blesses it ([`stability-jsdoc-tags.md`](./stability-jsdoc-tags.md)): `Implement`, `TrpcModule`, `TrpcHost`, `ImplementInterceptor`, `TRPC_MODULE_OPTIONS` (named `experimental_*` in `@trpc12/nest` until 2026-10-19, when the package became `@trpc12/experimental-nest`, whose name says it, [`stability-jsdoc-tags.md`](./stability-jsdoc-tags.md)). The option types keep their names, tagged `experimental`. Lost: serving the RPC protocol from the module (option C), and a stable Nest API before the human has used it.
- (agent) A separate package, `@trpc12/experimental-nest`, because it brings its own peers (`@nestjs/common`, `@nestjs/core`, `rxjs`, `@effect/platform-node`) ([`integration-packages.md`](./integration-packages.md)).
- (agent) Shape, after oRPC's: `@Implement(contract)` on a controller method adds the Nest route for the contract's REST mapping and an interceptor; the method returns the procedure (`impl.post.byId.query(…)`), so resolvers reach Nest-injected services through `this`. A leaf needs `.route({ path })`; a contract router (method returns `impl.router({ … })`) gets default paths from its keys, through `experimental_resolveRoute` from `@trpc12/trpc/openapi`. `TrpcModule.forRoot(options)` / `forRootAsync({ inject, useFactory })` is a global module.
- (agent) Serving: the module holds one `experimental_createOpenApiHandler` (so the `layer` is built once and disposed on shutdown), and its new `serve(request, { path, procedure, route?, params })` skips route matching because Nest already routed. Nest's Node request and response are bridged by Effect, not by hand: `NodeHttpServer.makeHandler` from `@effect/platform-node` around `toHttpEffect` from `@trpc12/trpc/http`, which already replays bodies Express parsed. Urlencoded bodies Nest parsed go back through `experimental_toBracketNotation`.
- (agent) `createContext`'s `platform` is Nest's `ExecutionContext`, so ctx can read whatever guards attached to the request.
- (agent) Nest's own pipeline runs first: guards, pipes and filters apply to the generated routes, with method metadata copied onto each route a router adds (put `@Implement` topmost).
- (agent) `TrpcHost` owns one `Scope`: the OpenAPI handler's `dispose()` is its first finalizer and `NodeHttpServer.makeHandler` runs request fibers in it. `onApplicationShutdown` closes it, ending requests in flight and then disposing the handler and its layer. `serve()` waits for the response through `Effect.callback` ([`effect-internal-patterns.md`](./effect-internal-patterns.md)).
- (agent) `TrpcModuleOptions.runtime` takes a caller-owned `ManagedRuntime` instead of `layer`, so a Nest app can share one runtime between its providers and its procedures. It goes to the OpenAPI handler's own `runtime` option, whose `dispose()` leaves the runtime running, so `app.close()` ends the requests and the caller's `runtime.dispose()` releases the services. `TrpcModuleOptions` is a type alias ending in `{ layer?; runtime?: undefined } | { runtime; layer?: undefined }`, so passing both is a type error, as in the handlers; it isn't typed by router. Passing both also throws when the module is built, for untyped callers, since the handler would silently take `layer`. What's lost: an interface (no declaration merging), and the type error reads "`Layer<…>` is not assignable to type `undefined`" on `layer` rather than naming the rule; the members' jsdoc does. `layer` stays as the Nest-owned convenience (second pass, under [`effect-first-public-apis.md`](./effect-first-public-apis.md)).
- Why: contracts are the part of @trpc12/trpc that doesn't need a router at startup, which is what Nest's decorator-per-method model wants; reusing the OpenAPI handler keeps one REST behavior (errors, coercion, SSE).
- Lost: the RPC wire protocol from Nest (REST only; serve `createFetchHandler` with `app.use` for RPC); Fastify and other Nest adapters (Express only); type-level checks that every contract leaf is implemented across controllers, or that the module's `layer` provides what procedures need (a missing service fails the call).
- Lives in: `packages/experimental-nest/src/index.ts`, `packages/experimental-nest/src/index.test.ts`, `packages/trpc/src/openapi/handler.ts` (`serve`, `OpenApiCall`), `src/openapi/rest/routes.ts` (`experimental_resolveRoute`, now public), `packages/trpc/src/openapi/openapi.test.ts` (`serve()`), `www/docs/integrations/nestjs.md`.
