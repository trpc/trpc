# The v12 docs live in `next/www/docs`, and everything else links the site (human)

- Human, 2026-10-20: "I'm not sure why we have or need docs in next/docs...we have the website and can always link that instead. Delete it and make sure things are ported to www. Only keep the readme files".
- (agent) `next/docs/` was the site's v12 content, not a copy of it: `contentDir` in `www/vite.config.ts` and the page glob in `www/src/content/docs.ts` read it, and the site rendered every one of its 86 pages (the two kitchen-sink pages, with their `demo` fences, included). Nothing there was off the site except `docs/README.md`, a hand-kept index of the pages. So the pages moved as they were, with their slugs, URLs, frontmatter and Twoslash app (`www/samples/docs`); nothing had to be ported.
- (agent) They're in `www/docs/`, beside the copies in `www/v11/docs/`, `www/v10/docs/` and `www/v9/docs/` and the blog in `www/blog/`. Not `www/content/`, which reads like `www/src/content/`, the code that loads pages; not `www/v12/docs/`, because `www/v<n>/` holds generated copies that nobody edits. Links from a page out of the folder (examples, spikes) gained a `../`, and `contentPath: 'www/docs'` makes them resolve to the same GitHub URLs as before.
- (agent) `docs/README.md` is dropped, not moved: the sidebar, the Experiments menu and `llms.txt` already list every page from its frontmatter, so the index repeated them by hand, and it had drifted (it still said experiment pages are `noindex` and left out of `llms.txt`, which changed on 2026-10-19). Every new page also edited it, which made it one of the files most likely to conflict. `next/README.md` links the site instead. "Only keep the readme files" means the package and example READMEs, which stay.
- (agent) Outside `www/docs/`, a page is linked by its URL on the site, `https://v12.trpc.io/v12/docs/<slug>` (`site.url` and `v12.basePath`), not by its path. That covers the package READMEs, which npm shows; the example READMEs; the codemod's steps, which `@trpc12/upgrade` prints for users who don't have the repo; and links in `.agent-docs/`. `tooling/pack/docs.test.ts` reads `site` from `@trpc12/www/site` (a devDependency), so when `site.url` moves to trpc.io, the READMEs fail the test until their links move too. Paths named in prose, such as the `Lives in` bullets and test titles, now say `www/docs/…`.
- (agent) The other readers moved with the pages: `pnpm lint:docs` and `vp staged` read `www/docs/`, `trpc/jsdoc` (`docs-use.ts`) looks for the nearest `www/docs/`, the "Edit this page" link opens `next/www/docs/<slug>.md`, and the Vercel ignore step needs no extra input now, because `www` is the project itself. CI's path filters (`next/**`) didn't change.
- (agent) A v12 page's last-modified date (sitemap `lastmod`, `dateModified`) skips the commits that renamed it (`datesSkipRenames` in `www/build/content.ts`), so the move didn't make every page new. The copies don't skip renames: following theirs reaches trpc.io's history and changes their dates. In a full clone every page kept its date. Vercel's production build clones 10 commits deep, and a shallow clone's oldest commit adds every file, so there a page untouched in those commits gets that commit's date, as it did before the move.
- Why: the docs had two homes, a folder meant for reading on GitHub and the site that renders it. Now they have one, the site's, and everything outside it links the place readers actually go.
- Lost: reading the docs as a Markdown tree from `next/` (they still render on GitHub at `next/www/docs/`, but nothing links there), and the hand-kept index. README and example links now point at `v12.trpc.io`, so they have to change at the trpc.io cutover.
- Open: at the cutover, update `https://v12.trpc.io/v12/docs` wherever it's written: READMEs, examples, `packages/upgrade/src/transform.ts` and `.agent-docs/`. `tooling/pack/docs.test.ts` only catches the package READMEs. And whether v12.trpc.io's `lastmod` dates should be right, which needs a deeper clone on Vercel than its 10 commits.
- Lives in: `next/www/docs/`, `next/www/vite.config.ts` (`contentDir`, `contentPath`), `next/www/build/markdown.ts` (`resolveLink`), `next/www/build/content.ts` (`lastModified`), `next/www/src/content/docs.ts`, `next/www/src/components/doc-page.tsx`, `next/tooling/pack/docs.test.ts`, `next/tooling/docs-lint/docs-lint.ts`, `next/tooling/oxlint-plugin/docs-use.ts`, `next/tooling/vercel-ignore/src/bin/ignore.ts`, `next/packages/upgrade/src/transform.ts`, `next/packages/*/README.md`.
