# `/sponsor` sells the tiers, and trpc.io's `/pricing` goes there (human asked)

- Human, 2026-10-20, on aligning trpc's and KATT's GitHub Sponsors tiers: "silver and above should be "partners" as you can see on the new v12 website"; on the tier texts proposed: "the rest looks good".
- Human, 2026-10-20: "pricing can redirect to a new sponsorship page that is a bit more engaging"; "the sponsor page should write something fun about we need the money for TOKENS"; later: "delete "pro" plan from the wording and the whole FAQ and the links to alex sponsor"; "the "become a partner" should probably link to /sponsor too etc".
- (agent) `/sponsor` is a page of its own: a hero with the sponsor count, a "We need the money for tokens" section (v12 is written mostly by agents, with a terminal running out of credits), the four monthly tiers as cards ($50 Indie, Bronze, Silver and Gold, the last two badged Partner), where partners show up (the current partners and a "Your logo here" slot), and the sponsor cloud. No FAQ, no mention of the old Pro plan, and no link to KATT's listing: the page sells the trpc organization's tiers only. The tier cards say what the GitHub tiers say; each button opens that tier's checkout on the trpc organization's listing (`sponsorTierUrl`, GitHub's numeric `tier_id`). Bronze, Silver and Gold take their prices from `sponsorTiers`, so a threshold the site groups by is the one the page sells.
- (agent) trpc.io's `/pricing` (its Pro plan was the $500 tier, now Silver) redirects to `/sponsor` (308, `retiredPages`) instead of back to trpc.io. trpc.io's `/sponsor`, a redirect to GitHub Sponsors, is this page here: a served page wins over an old redirect. `/buy/tier-pro` still goes straight to the Silver checkout.
- (agent) Every way into sponsoring on the site lands here: the footer's Sponsors link, the home page's "Become a sponsor" and the docs' "Become a partner →". Only this page links to GitHub Sponsors, from its hero and from each tier's checkout. This replaces "Become a sponsor" going straight to GitHub Sponsors in [`docs-sponsors.md`](./docs-sponsors.md); the "Tiers and perks" link that sat beside it is gone, as it went to the same place.
- Why: the old pricing page sold a plan the tiers no longer match, and a link to GitHub Sponsors can't say what a partner gets on this site.
- Lost: the Pro plan's own list (non-MIT packages, two hours of consulting a month): Silver keeps the priority and the Discord channel; Gold has the monthly consulting session.
- Open: the GitHub tier texts are pasted by hand (GitHub's API can't edit a tier), so they and the cards can drift.
