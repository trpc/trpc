# v11 is what the site opens with; v12 is at `/v12/docs` and behind a switch on the home page (human asked)

- Human, 2026-10-18: "make it so v11 is still the default and that all the v12 stuff is under /v11 routes / front page should have a switcher like raf-query (just steal that code and make it be sticky in the same way until sponsors section) - default to the v11 one".
- (agent) "/v11 routes" is read as `/v12`: v11 the default means its docs at `/docs`, where trpc.io has them, so v12's go under `/v12/docs`. The v11 copy's old address, `/v11/docs/*`, redirects (308) to `/docs/*`, and trpc.io's URLs land on v11's page at the same path ([`old-urls-and-seo.md`](./old-urls-and-seo.md)); old links to `/docs/*` meant for v12 now land on v11's page at that slug, or a 404 when there's none. `llms.txt`, `llms-full.txt`, the `.md` twins, `Accept: text/markdown` and the sitemap stay v12's, at `/v12/docs` ([`docs-website-on-vercel.md`](./docs-website-on-vercel.md)): the copies are trpc.io's, and their canonical links point there ([`old-docs-copy.md`](./old-docs-copy.md)).
- (agent) The home page's switch is raf-query's framework-mode bar (`.repos/raf-query/www/src/components/framework-mode-bar.tsx`, `framework-mode-bar-layout.ts`, `framework-mode.ts`): a "v11" / "v12 preview" pill docked above the hero's code that sticks under the header as the page scrolls and lets go where the Sponsors section starts (raf-query lets go after "How it works"). On wide screens it drifts toward the middle of the viewport as it sticks, unless the reader prefers reduced motion. v11 is the default; `?version=v12` selects v12, so the choice is a link.
- (agent) As in raf-query, both versions are in the prerendered HTML, and CSS shows one (`[data-home-panel]`, `html[data-home-version]`). A blocking script in the head sets the attribute from `?version=` before the first paint, so `/?version=v12` doesn't flash v11. The hero's text, badge, install line and code, the three steps and the features have a panel per version; the headings, "Supported by" and Sponsors are shared. Header links, the docs version switcher and the not-on-npm strip follow the panel on the home page and the docs version elsewhere.
- (agent) The v11 view is trpc.io's home page: its hero, its three steps' text and links, and its six features. The steps' code is the copy of trpc.io's `landing-intro` steps that `old-docs:copy` writes to `www/v11/home/`, so it follows trpc.io.
- Human, 2026-10-18: "and when you're on v12 in the docs and click the logo or a home link you should end up at `?version=v12`". Links to the home page (the header's logo, the footer's Sponsors, the 404 page's Home) take `useHomeSearch()` (`www/src/content/docs.ts`): `/?version=v12` from v12's docs, the version shown on the home page itself, and `/` everywhere else, the blog included. They're in the prerendered HTML, so they work before hydration.
- Why: until v12 is published, a reader who lands on the site should get the tRPC they can install; v12 stays one click away.
- Lost: `/docs/*` URLs of v12 pages shared before 2026-10-18.
- Open: switching the default to v12, and `/docs` with it, when v12 is released.
