# `dedupeLink` compares inputs deeply, copies streams to their readers and shares subscriptions (human asked)

- Human, 2026-10-18: "I guess all it needs to do is to keep track of the inputs and do a deep equal check like above? It doesn't need to sort". Calls share a request when the path matches and the inputs are deeply equal, in any key order. The input isn't serialized any more, so a `File` or a type only `httpLink`'s serializer knows no longer throws.
  - (agent) Only data compares by content: plain objects, arrays, `Map`s, `Set`s, `Date`s, `URL`s, `URLSearchParams`, `Headers`, `RegExp`s, typed arrays. Anything else equals only itself, and a missing key differs from `undefined`. A wrong "no" costs a request, a wrong "yes" hands a caller another call's result.
  - (agent) The link keeps a reference to the first caller's input, not a copy: changing an input while its call is in flight isn't supported (with batching, `httpLink` serializes it later anyway).
- Human, 2026-10-18 ("2 seems good"): calls must also have equal call options. `headers` and `init.headers` compare as `Headers`; `dedupe` and `onResponse` are left out. Each caller's `onResponse` is called, including for responses that came before it joined, and one that throws fails only that caller.
- Human, 2026-10-18: "Fresh requests for streamed queries if it has started seems good, but if it hasn't we can tee it?". An `AsyncIterable` or `ReadableStream` in a shared result is read once and copied to every caller that starts reading before an item has been read. A caller that starts later, or after every reader stopped, sends its query again and reads that response's stream.
  - (agent) Items are buffered per reader until it reads them; a caller that never reads costs nothing. When the last reader stops, the source is closed. Once every caller holding the result has aborted, the shared request is aborted, so an unread stream doesn't keep it open.
  - (agent) Promises in the result stay shared. Streams are found in plain objects and arrays, not in `Map`s, `Set`s or inside a stream's items.
- Human, 2026-10-18: "if it's a subscription, tee it but consider last event I'd equality as part of the input". Subscriptions with the same path, deeply equal inputs, equal call options and the same `lastEventId` share one upstream, copied to each subscriber; the end and errors reach all of them. `key(op)` replaces only the input comparison, so `lastEventId` is still compared under it.
  - (agent) A subscriber joins only before the first event, the same rule as a stream in a query result. Joining later would miss events: those replayed after its `lastEventId`, or a snapshot the resolver sends first. A later subscriber subscribes on its own, and others can join that one before its first event.
  - (agent) The upstream stops once every subscriber has stopped or aborted. `onResponse` fans out like a query's, replayed to a subscriber that joins after a response. A stream in an event is copied to every subscriber when the event arrives (not when it starts reading), since a subscription can't be sent again for one late reader; a subscriber that never reads it buffers its copy until the stream ends.
- Why: the serialized key missed equal inputs in another key order and threw on inputs the default serializer can't write; ignoring call options gave a caller a response sent with another caller's headers; a shared stream split its items between readers and could hang. Subscriptions that start together (components mounting at once) opened one connection each.
- Lost: `key(op)` used to replace the whole comparison; call options are now compared under it too. A late reader's stream comes from a second run of the query. Subscriptions passed through untouched; a subscription that must have its own connection now needs `dedupe: false`.
- Open: letting a subscriber join after events when the link can tell it would miss none (no `lastEventId` and a resolver that sends no snapshot), which the link can't know today.
- Lives in: `packages/trpc/src/client/links/dedupe.ts`, `links/equal.ts`, `links/dedupe.test.ts`, `links/equal.test.ts`, `docs/client/links/dedupe.md`.
