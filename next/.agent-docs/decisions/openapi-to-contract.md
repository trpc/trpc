# OpenAPI to contract is a source generator on Effect's `SchemaRepresentation` (agent)

- Closes the "OpenAPI-to-contract (Hey API plugin)" Open in [`openapi.md`](./openapi.md) and [`openapi-type-generator-v1.md`](./openapi-type-generator-v1.md). oRPC does it as a Hey API plugin; Effect 4 already translates JSON Schema to Effect Schema source (`JsonSchema.fromSchemaOpenApi3_0/3_1`, `SchemaRepresentation.fromJsonSchemaMultiDocument`, `toCodeDocument`), the same pipeline as `@effect/openapi-generator`. Effect-native first ([`effect-native-by-default.md`](./effect-native-by-default.md)): build on it, with no new dependency.
- (agent) `generateContractFromOpenApi(document, { prefix = '', exportName = 'contract', patterns = 'ignore' })` in `@trpc12/trpc/openapi` returns a module's source: exported Effect Schemas for components and for each operation's input, output and error `data`, and a contract of resolver-less procedures with `.route({ method, path, successStatus? })` ([`contracts.md`](./contracts.md)). Source, not a runtime contract, so the types are real and reviewable in a diff.
- (agent) Mapping: `operationId` dots nest; without one, `camel(method + path)`. `GET` → query, `text/event-stream` → subscription, else mutation. Path and query parameters merge with the JSON (or form) body into one input, matching `inputStructure: 'compact'`, so `openApiLink` sends them back where they came from. Two operations on one procedure path throw.
- (agent) Open objects (no `additionalProperties`) are closed, because Effect renders them as `StructWithRest` with a `Json` index signature, which makes poor client types; decoding still ignores excess keys. Objects merged by `allOf` (inline or by `$ref`) stay open, since two closed objects never intersect.
- (agent) Error responses with @trpc12/trpc's error shape (`code` const, `data`) become `.errors({ CODE: { status, data } })`; `BAD_REQUEST` is skipped, as every input gets it. Other APIs' errors stay `UnexpectedError`.
- (agent) `pattern`s default to `'ignore'`: Effect rejects them by default, and applying an untrusted regex is a ReDoS risk.
- Lost: a CLI (it's a function, like `generateOpenApiFromTypes`); `tracked()` subscriptions (OpenAPI can't say); multipart file types (bodies are typed from their JSON Schema); non-JSON responses.
- Lives in: `packages/trpc/src/openapi/to-contract.ts`, `src/openapi/index.ts`, `packages/trpc/src/openapi/to-contract.test.ts`, `packages/trpc/src/openapi/fixtures/generated/` (file snapshots, typechecked), `docs/openapi/from-document.md`.
