# Internal logic is written in Effect (human)

- Human, 2026-10-15 (decisions round 3, Q2): "all logic we write should use Effect except some public facing apis".
- Internals (control flow, concurrency, streams, resources, retries, timeouts, errors) are Effect: `Effect`, `Stream`, `Queue`, `Deferred`, `Scope`, `Fiber`. Not hand-rolled promise chains, `setTimeout` loops or callback bookkeeping.
- Public APIs can stay Promise- and callback-shaped where users expect them (`client.x.query()`, `for await`, `createContext`, TanStack's `mutationFn`), converting at the edge.
- Why: one model for interruption, cleanup and typed failures, and the parts compose with users' Effect code and layers.
- Lost: zero-dependency, framework-free internals.
- (agent) Moved in round 3: the file-bytes wait in `serializer/stream.ts` (a `Deferred` per byte stream and per target, waits as fibers instead of promise chains) and `httpLink`'s batching (`Queue`s instead of a hand-rolled async queue, each batch an `Effect` run as a fiber, scheduling with `Effect.sleep(0)`) and SSE reconnect loop (`Stream` plus `Effect.sleep` backoff, no `setTimeout`). The rest still moves as it's touched.
- (agent) Moved after round 3: `socketLink` holds its connection in an `RcRef` (shared by calls; `idleMs` is its idle time-to-live; a lost connection is invalidated), each call reads its own `Queue` inbox on a fiber with an `Effect.sleep` reconnect loop, and keep-alive is a fiber in the connection's scope. No `setTimeout`/`setInterval` or promise chains. `DeferredDecoder` is `makeDeferredDecoder()` returning effects; a value's head decodes on its own fiber so later chunks (file bytes) keep flowing, which also fixed files inside SSE subscription events hanging.
- (agent) Moved 2026-10-18: server WebSocket, raw socket and v11 `wsLink` sessions run on Effect's `Socket` through one runner, with a `FiberHandle` idle timer instead of `setTimeout`, and each socket or MessagePort call is a fiber in a `FiberMap` instead of an `async` function with an `AbortController` ([`websocket-sessions-on-effect-socket.md`](./websocket-sessions-on-effect-socket.md)).
- (agent) Moved 2026-10-18: the handler core builds the layer's services with the `ManagedRuntime`'s `contextEffect` instead of a cached `Promise`, and `run` is the same Effect as `runEffect`, run at the edge ([`handler-core-on-effect.md`](./handler-core-on-effect.md)).
- (agent) Moved 2026-10-18: lazy routers load through one `Effect.cached` Effect per subtree instead of a memoized `Promise`, and `resolveProcedure` and `loadRouter` run Effects at the edge ([`lazy-routers-on-effect.md`](./lazy-routers-on-effect.md)).
- Lives in: all of `packages/trpc/src/`; the moved internals are `src/server/sockets/socket-session.ts`, `src/server/sockets/socket.ts`, `src/serializer/stream.ts`, `src/client/links/http.ts`, `src/client/links/socket.ts` and `src/client/links/events.ts`; tests in `packages/trpc/src/server/sockets/websockets.test.ts` (`close()` cases) and `packages/trpc/src/server/handler/files.test.ts` (files inside subscription events).
