# OpenAPI: a REST handler plus a generator (agent)

- Human, 2026-10-15 (Q18.4): "V1". `experimental_openApiLink` ships in v1.
- (agent) Q18.1: O-C. Skipped in the decision round, 2026-10-16; kept O-C because it is built, gives oRPC parity, and RPC users get a spec with no configuration. `experimental_createOpenApiHandler({ router, prefix = '/api', createContext?, layer?, plugins? })` serves the REST mapping and is the main feature. `experimental_generateOpenApi(router, { info, servers?, target: 'openapi' | 'rpc', prefix?, filter? })` documents the REST mapping or, with zero configuration, the RPC endpoint (`{ json }` bodies included).
- (agent) Q18.2: defaults. Skipped in the decision round, 2026-10-16; kept because the whole router is usable over REST with no configuration, as in oRPC. Without `.route()`, a query is `GET {prefix}/post/byId`, a mutation `POST`, a subscription `GET` with `text/event-stream`.
- Requests:
  - Path params are `{name}`; static segments win, so `/posts/latest` matches before `/posts/{id}`. Two procedures on one method and path throw at creation.
  - `GET` reads the query string; other methods read a JSON, urlencoded or multipart body. Path params are merged into the input.
  - Bracket notation (`a[b]=1&tags[]=x`, plus repeated keys) in query strings and forms. Leaves are strings, or `File`s in forms.
  - Non-JSON bodies from other origins are refused with a 403 by default ([`openapi-csrf-guard.md`](./openapi-csrf-guard.md)).
  - Strings are coerced from the input's JSON Schema to numbers, integers, booleans, `null`, enum or const values, and single-item arrays; anything the schema doesn't describe is left for validation. JSON bodies aren't coerced; path params always are.
- Responses are plain JSON, no danSON. A `Blob` or `File` output is the body. Errors are `{ defined, code, status, message, data? }` with the error's status. Deferred values aren't supported over REST.
- The spec is built from Standard JSON Schema (`~standard.jsonSchema`, `unrepresentable: 'any'`) and Effect's `Schema.toStandardJSONSchemaV1`, so there's no per-library converter. `$defs` are hoisted into `components.schemas`. Declared errors become responses by status; procedures with an input document the 400 validation error; `default` documents the error format.
- Q18.3: later; the static TypeScript generator isn't ported.
- `experimental_openApiLink({ url, contract })` reads methods and paths from an `experimental_toContract()` value, sends `multipart/form-data` when the input contains a `Blob`, and reads SSE for subscriptions.
  - (agent, 2026-10-20) Its internals are Effects, as `httpLink`'s are ([`internals-use-effect.md`](./internals-use-effect.md)). A call's `AbortController` is acquired with `Effect.acquireRelease` in the call's scope, so interrupting it aborts the fetch and the body read; a subscription's scope is its stream's, through `Stream.unwrap`. SSE events come from `sseEvents` over `Stream.fromReadableStream`, which cancels the body when the reader stops, instead of an `async function*` over `parseSse` and `Stream.fromAsyncIterable`. The async request, error and result helpers are `Effect.tryPromise`/`Effect.try` steps with the same error mapping. Events decode with `Stream.mapAccumEffect`, since `Stream.mapEffect`'s concurrent machinery was 2.3 kB of the link. Gzipped: +483 B on the link alone (20,289 → 20,772); the budgeted clients don't include it. Tests: `packages/trpc/src/openapi/openapi-edges.test.ts` (a stopped subscription aborts and cancels; a `TrpcError` from `fetch` passes through).
