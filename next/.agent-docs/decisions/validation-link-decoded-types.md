# `experimental_validationLink({ output: 'json' })` types as decoded only the results it decodes (agent)

- Found while compiling the examples of the open question that became [`validation-link-error-data.md`](./validation-link-error-data.md): the link declared one form (`ProgressiveJsonForm`) for the whole chain, which typed every result and every error's `data` as the schemas' types. At runtime it decodes only the results of the contract's procedures whose output schema validates, so a `Date` arrived as a `string` while typed `Date` in errors' `data`, `stream()` items, outputs of procedures without an output schema (a router used as the contract), `.output(schema, { validate: false })` outputs, and paths the contract doesn't have.
- (agent) The link declares the contract it decodes with instead of a form: `LinkDecl` gains `decodes?: object`, and `experimental_validationLink<TContract>({ contract, output: 'json' })` declares `{ decodes: TContract }`. Every link's form is unchanged, so the chain's form stays the transport's (plain JSON behind `httpLink`'s default serializer).
- (agent) The Promise client, the Effect client and `inferRouterOutputs` walk the contract beside the router once per client, when the links declare `decodes` and no explicit client form overrides it. A procedure gets the decoded form only where the contract has a procedure at the same path whose output is validated and isn't streamed; everything else gets the links' form. The decoded form is `ProgressiveJsonForm`, declared errors' `data` included, since the link decodes it too; other errors keep their `data` in the links' form ([`validation-link-error-data.md`](./validation-link-error-data.md)), and `matchError()`, `safe()`, `createSafeClient`, the Effect client and TanStack Query's hooks follow it through `ClientError`.
- (agent) "Validated" is a type-only marker on procedure definitions, `outputValidated: true`: `.output(schema)` on a procedure builder and `.output()` on a contract builder set it, `.output(schema, { validate: false })` and a procedure without `.output()` leave it `never` (a built procedure's def leaves it out, with `declared`, the codes `.errors()` lists: [`sanitized-procedure-types.md`](./sanitized-procedure-types.md)), and `.concat()`, `t.extend()` and `implement()` carry it. Subscriptions are validated like queries, so a validated one's events are typed decoded.
- Why: the types say what arrives, the rule of [`links-declare-result-form.md`](./links-declare-result-form.md), and one shape covers every case where the link passes a value through, instead of a form field per case (the earlier `errorData` and `streamedOutput` on `OutputForm`). `DecodedJsonForm`, exported from `@trpc12/trpc/transformer`, is gone: a direct `ClientValue<T, DecodedJsonForm>` claimed every value decoded, which no form can say; only a chain with a decoding link gets per-procedure forms.
- Why this formulation (`pnpm bench shapes`, 1,500 procedures, with the client, against `v12` before the change): `plain` +122 (a constant), `match` +122, `streamed` −2,890, `infer` −154, `effect client` +6,125 (4 per procedure, 0.3%), `contract` +4,646 (3 per procedure, from carrying the marker). A chain with the decoding link (local `validated` shapes: `output` and `errors` procedures, the router as the contract) pays the walk: +60,806 (40 per procedure, 3.4%) on calls, the same on `matchError()` (2.3%). Mapping plain JSON to a fixed `DecodedJsonResultForm` instead of a generic `DecodedResultForm<JsonForm>` saved 97 per procedure on `matchError()`.
- Lost: a form alone no longer says what a decoding chain's results are, so a type helper outside the client (`ClientValue<T, F>`) can't express "decoded" without the contract. Decoding `stream()` items on the client (with the stream schema's item) would type them decoded; it would wrap every streamed output and ship the schemas' codecs, so the link keeps passing them through.
- (agent) Declared errors' `data` is decoded as well, so the decoded form dropped `errorData` ([`validation-link-error-data.md`](./validation-link-error-data.md)).
