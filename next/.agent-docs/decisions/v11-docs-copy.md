# The v11 docs, copied into the site at `/v11/docs` (human asked)

- Human, 2026-10-17: "Also try to think of a way to programatically copy all of the previous docs (ignoring twoslash etc, just doing ts formatting) and have link to previous docs line docusaourus has / We don't wanna maintain them nor we wanna delete them for now / Would be nice to have a switcher where we show current is experimental version ​and each correspondent page should have a link to v11 links if there is one like hteir default thing does". This supersedes "ignore v11 linking etc for now" in [`docs-website.md`](./docs-website.md).
- (agent) `pnpm --filter @trpc12/www v11:copy` (`www/build/v11-copy.ts`) reads the v11 Docusaurus site in the repo root's `www/` and writes every page of its sidebar to `next/www/v11/docs/<slug>.md`, at trpc.io's slugs (`/docs/server/procedures` is `/v11/docs/server/procedures`), with the sidebar's sections in `v11/sections.json` and the images the pages show in `www/public/v11/img`. The copy is committed, and nobody edits it: after the v11 docs change, run the copy again. Leaving the v11 docs alone means leaving the copy alone.
- (agent) The conversion (`www/build/v11-convert.ts`) is pure and turns MDX into this site's Markdown: Twoslash blocks become the plain code trpc.io shows (hidden setup, `// @…` directives and `// ^?` markers go, `// @include:` is expanded), admonitions become alerts with their titles, `<Tabs>` become tab groups (package managers switch with the install commands), partials, `<InstallSnippet>`, `<YouTubeEmbed>`, SVG imports and the static components are inlined, HTML comments go, and links point at the copied pages, or at trpc.io for the blog, the API reference and the v9/v10 docs. Anything else fails the copy, so a new construct in the v11 docs doesn't render as raw MDX. Links to headings that don't exist lose their `#hash`, since Docusaurus only warns about them and this site's build fails on them.
- (agent) The site serves the copy with a second instance of the docs plugin (`build/content.ts`, `virtual:v11-docs-manifest`), without twoslash, agent files or the sitemap: each page's canonical link is its trpc.io URL, where the v11 docs stay maintained.
- (agent) As in Docusaurus, a version dropdown in the header switches between "v12 experimental" and "v11 stable", landing on the page of the same topic, and every page has a banner that says which version it is, linking to its counterpart in the other version or else to that version's first page. A v12 page's counterpart is the v11 page its `v11` frontmatter names, or the v11 page at its own slug; a v11 page's is the v12 page at its slug, or else the first v12 page that names it. Search looks in the version being read.
- Why: v11 readers keep their docs next to v12's, linked page by page, at no upkeep: the copy is generated, and trpc.io stays the source.
- Lost: Twoslash types in the v11 code blocks, and the generated API reference (it links to trpc.io); edits to the copy, which the next copy overwrites.
- Open: retiring the copy once v12 is stable; mapping more v12 pages to their v11 topics.
