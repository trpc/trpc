# `@trpcdev/upgrade` rewrites v11 source for v12 and lists what's left (human asked)

- Human, 2026-10-15 (decisions round 3, Q3): "we'll provide codemods, migration guides, and special interop request handlers for old clients". Closes the codemod Open in [`no-backwards-compatibility-yet.md`](./no-backwards-compatibility-yet.md).
- (agent) A package, `@trpcdev/upgrade`, with a `trpcdev-upgrade <paths…> [--write]` bin: a dry run by default, printing the files it would change and `file:line:column` notes for the steps it can't do. `upgradeSource(source, filename)` is the pure core; `upgradeFiles` and the CLI are Effect (`FileSystem`, `Path`, `effect/cli`), run with `NodeServices`.
- (agent) Parsed with `oxc-parser` and edited in place with `magic-string`, not printed from an AST: formatting and comments stay, and only touched spans change. No jscodeshift or ts-morph: they bring a printer and a TypeScript program we don't need.
- (agent) Rewrites only what has one v12 form: `@trpc/*` imports (renamed names deduplicated, aliases and `type` kept), `initTRPC.context<C>().meta<M>().create()` → `initTrpc<{ ctx: C; meta: M }>()`, `TRPCError` → `TrpcError`, `t.mergeRouters(a, b)` → `{ ...a, ...b }`, `router.createCaller(ctx)` → `createRouterClient(router, { ctx })`, `fetchRequestHandler({ req, … })` → `createFetchHandler({ … }).fetch(req)`, the batch/stream/subscription links → `httpLink` (`batch: true` for batch links), a link's `transformer` → `serializer: createSyncSerializer(transformer)`, `maxURLLength` → `maxUrlLength`, and `createTRPCContext`'s `TRPCProvider`/`useTRPC`/`useTRPCClient` (also where other files import them) plus `trpcClient=` → `client=`.
- (agent) Everything else is a note, not a guess: root `transformer`/`errorFormatter`/`isDev`, observables, adapters (standalone, express, ws, next, lambda), `@trpc/react-query`/`@trpc/next`, `createWSClient`, `createCallerFactory`, `createTRPCOptionsProxy`'s `queryClient`. A note names the v12 way and the guide section.
- (agent) A file is only parsed when it mentions `@trpc/` or one of the `createTRPCContext` names; `node_modules`, `dist`, `.git`, `.next` and `.output` are skipped.
- Lost: no type-aware rewrites (a `TRPCClientError<AppRouter>` type argument, `observable()` bodies), no `throw` → `return error()` (both work in v12).
- Lives in: `packages/upgrade/src/` (`transform.ts`, `files.ts`, `cli.ts`, `bin.ts`, `transform.test.ts`), `docs/migrating-from-v11.md`.
