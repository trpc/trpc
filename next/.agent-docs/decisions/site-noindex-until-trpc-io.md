# The site isn't indexed until it's trpc.io (human)

- Human, 2026-10-19: "but v12.trpc.io should not indexable until it is upgraded to trpc.io". Its first half, indexing experiments' pages, was taken back on 2026-10-20: they stay `noindex` after the cutover ([`docs-experiments.md`](./docs-experiments.md)).
- (agent) The switch is `site.url` in `www/src/site.ts`. A build is indexable (`indexable` in `www/src/seo.ts`) only when `site.url` is `https://trpc.io` and Vercel builds it for production (`VERCEL_ENV=production`). Changing `site.url` at the cutover turns indexing on; `public/robots.txt`'s `Sitemap:` changes with it (a test fails until it does).
- (agent) A build that isn't indexable (v12.trpc.io now, every preview, a local build) says `noindex` twice: every page has `<meta name="robots" content="noindex">` (the root route's `head()`), and on Vercel every response, markdown, `llms.txt` and images included, has `X-Robots-Tag: noindex` (the first route `build/vercel-output.ts` writes). Once the build is indexable, the header stays on every host but `trpc.io` (a `missing` host condition), so an old v12.trpc.io alias and the deployment's `*.vercel.app` URLs stay out of search results.
- (agent) `robots.txt` keeps `Allow: /` and the sitemap: a crawler that may not fetch a page never sees its `noindex`, and Google can still list a blocked URL it finds in links. The sitemap lists the v12 pages as before, so it's ready the day the switch flips.
- Why: until v12 replaces v11 at trpc.io, its docs shouldn't compete in search with trpc.io's, and keying on the site's URL and the deployment means the cutover is one edit that can't leave the old host or previews indexed.
- Lost: search traffic to v12's docs before the cutover; per-host meta (prerendered HTML is the same at every host, so off trpc.io after the cutover only the header says `noindex`).
- Open: at the cutover, what [`old-urls-and-seo.md`](./old-urls-and-seo.md) leaves open (the copies' canonical links, the `onTrpcIo` redirects).
- Lives in: `next/www/src/site.ts` (`url`), `next/www/src/seo.ts` (`indexedHost`, `indexable`), `next/www/src/routes/__root.tsx`, `next/www/build/vercel-output.ts` (`noindexRoute`), `next/www/public/robots.txt`.
