# `.concat()` drops leading middleware both sides share; no request-wide dedupe (agent)

- oRPC dedupes router middleware that a procedure already starts with (`dedupeLeadingMiddlewares`). Plain-object routers ([`routers.md`](./routers.md)) have no router-level middleware, so the only place two chains meet is `.concat(plugin)` (and `t.with(ext)`, built on it; [`keep-t-object.md`](./keep-t-object.md), [`root-extensions.md`](./root-extensions.md)).
- (agent) `.concat(plugin)` skips the plugin's leading steps that equal the builder's own leading steps: the same middleware function, the same input schema, or the same `.provide()` key and factory, in the same order. A plugin built on the app's session middleware runs it once. Later duplicates still run.
- (agent, Effect-native first) Request-wide "run once" is left to Effect and ctx: services in the handler's `layer` are built once (Layer memoization), and middleware can reuse what ctx already holds (`ctx.db ?? connect()`), which covers nested `t.call()`s. A built-in memo for `.provide()` was rejected: factories receive `input`, so memoizing by identity would hand one call's value to another, and skipping an inner `provideService` breaks Effect's "inner provision wins".
- Lost: an opt-out like oRPC's `dedupeLeadingMiddlewares: false`; no one has asked to run the same middleware twice back to back.
- Later (human): keep or drop the dedupe after oRPC v2. Human, 2026-10-16 (decision round): "Later. Idk why we'd need both concat and with either". The dedupe stays as built until then; the second half became the composition answer in [`root-extensions.md`](./root-extensions.md) (`.concat()` everywhere).
  - The question was: oRPC v2 removed its automatic dedupe (`dedupeLeadingMiddlewares` is gone), so middleware applied twice runs twice, and documents the ctx-flag pattern instead (`ctx.authLoaded ? ctx.auth : load()`). Its `ratelimit({ dedupe = true })` dedupes explicitly by limiter and key. Options: A) keep the identity-based skip in `.concat()`; B) drop it and give `rateLimit()` its own per-call dedupe ([`rate-limit-on-effect-ratelimiter.md`](./rate-limit-on-effect-ratelimiter.md)).
