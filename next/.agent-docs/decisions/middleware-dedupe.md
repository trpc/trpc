# `.concat()` drops leading middleware both sides share; no request-wide dedupe (agent)

- oRPC dedupes router middleware that a procedure already starts with (`dedupeLeadingMiddlewares`). Plain-object routers ([`routers.md`](./routers.md)) have no router-level middleware, so the only place two chains meet is `.concat(plugin)` (and `t.with(ext)`, built on it; [`keep-t-object.md`](./keep-t-object.md), [`root-extensions.md`](./root-extensions.md)).
- (agent) `.concat(plugin)` skips the plugin's leading steps that equal the builder's own leading steps: the same middleware function, the same input schema, or the same `.provide()` key and factory, in the same order. A plugin built on the app's session middleware runs it once. Later duplicates still run.
- (agent, Effect-native first) Request-wide "run once" is left to Effect and ctx: services in the handler's `layer` are built once (Layer memoization), and middleware can reuse what ctx already holds (`ctx.db ?? connect()`), which covers nested `call()`s. A built-in memo for `.provide()` was rejected: factories receive `input`, so memoizing by identity would hand one call's value to another, and skipping an inner `provideService` breaks Effect's "inner provision wins".
- Lost: an opt-out like oRPC's `dedupeLeadingMiddlewares: false`; no one has asked to run the same middleware twice back to back.
- Open (human): oRPC v2 removed its automatic dedupe (`dedupeLeadingMiddlewares` is gone), and the migration guide flags that middleware applied twice now runs twice, with no warning. In its place it documents the ctx-flag pattern (`ctx.authLoaded ? ctx.auth : load()`, the same pattern as our request-wide bullet above). The one middleware that still dedupes does it explicitly: `ratelimit({ dedupe = true })` skips a limiter and key already applied in this call. Options: A) keep the identity-based skip in `.concat()`/`t.with()`; B) drop it, so composition never hides a step, and give `rateLimit()` its own per-call dedupe by limiter and key (today it relies on this skip; [`rate-limit-on-effect-ratelimiter.md`](./rate-limit-on-effect-ratelimiter.md)). Source: `.repos/orpc/apps/content/docs/migrations/from-v1.mdx` ("Automatic deduplication removed"), `.repos/orpc/packages/ratelimit/src/middleware.ts`.
