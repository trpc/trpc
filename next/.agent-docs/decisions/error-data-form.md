# Errors' `data` is typed in the form it arrives in, behind a link that decodes only outputs too (agent)

- Found while compiling [`open/validation-link-error-data.md`](../open/validation-link-error-data.md)'s examples: `experimental_validationLink({ output: 'json' })` declared `DansonForm`, which typed both its decoded outputs and the errors' `data` it doesn't decode as the schemas' types, so a `Date` in a declared error's `data` was typed `Date` and arrived as a `string`.
- (agent) `OutputForm` gains an optional `errorData?: OutputForm`: the form errors' `data` arrives in, for a `streaming` form whose outputs a link decodes. The link declares `DecodedJsonForm` (`DansonForm` with `errorData: JsonForm`), exported from `@trpc12/trpc/serializer` beside the other forms. `ErrorData` reads `errorData` only in its `streaming` branch, so `matchError()`, `safe()`, `createSafeClient`, the Effect client and TanStack Query's hooks, which all take their error types from `ClientError`, follow it. A transport's own serializer still decides as before: a danSON chain keeps `Date`s in errors' `data`, plain JSON makes them `string`s.
- Why: the types say what arrives, the rule of [`links-declare-result-form.md`](./links-declare-result-form.md). A form already says how values arrive, so the error side sits on it rather than in a second chain declaration (`errorForm` beside `form` on `LinkDecl`), which would need its own first-link-wins walk and its own override in `TrpcClient`'s explicit form.
- Why this formulation (`pnpm bench shapes --only plain,errors,match,contract`, 1,500 procedures, with the client): 0 added instantiations on all four shapes. Checking `errorData` first in `ErrorData` cost +4,506 on `match` (3 per procedure); resolving the error form once in `ClientError` cost +1,520 on every shape.
- Lost: an `errorData` on a non-`streaming` form is ignored; no link needs one.
- Open: whether the link decodes declared errors' `data` (and rebuilds their classes) at runtime, [`open/validation-link-error-data.md`](../open/validation-link-error-data.md). If it does, it declares `DansonForm` again.
- Lives in: `packages/trpc/src/internal/types.ts` (`OutputForm.errorData`, `DecodedJsonForm`), `src/client/types.ts` (`ErrorData`), `src/client/links/validation.ts` (overload), `src/serializer/index.ts`, `packages/trpc/src/client/links/validation.test.ts`, `www/docs/client/validation.md`, `www/docs/client/errors.md`, `www/docs/openapi/client.md`.
