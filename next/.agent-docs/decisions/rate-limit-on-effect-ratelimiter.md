# `rateLimit()` is Effect middleware over Effect's `RateLimiter` (agent)

- oRPC ships `@orpc/experimental-ratelimit`: its own `Ratelimiter` interface with memory, Redis, Upstash and Cloudflare adapters, a middleware and a handler plugin for headers. Effect 4 already has `RateLimiter` in `effect/persistence` (fixed window and token bucket, fail or delay, memory and Redis stores). Effect-native first ([`effect-native-by-default.md`](./effect-native-by-default.md)) means using it, not a second interface.
- (agent) `rateLimit<{ ctx }>({ key, limit, window, algorithm?, onExceeded?, tokens? })` from `trpcdev/middleware` is an Effect middleware that requires `RateLimiter.RateLimiter`, so a handler without it in `layer` is a type error. Its key function sees `ctx`, `input`, `meta` and `path`, typed by the requirement like `middleware<{ ctx }>()`.
- (agent) Past the limit it fails with the exported `RateLimited` (`TrpcError.Tagged('TOO_MANY_REQUESTS', { status: 429, data: { limit, retryAfter } })`, `retryAfter` in milliseconds), so the error is typed on the client. Store errors are defects (masked 500): they are not the caller's fault.
- (agent) Headers: `RateLimit-Limit`, `RateLimit-Remaining`, `RateLimit-Reset` (seconds) on every call, `Retry-After` on 429, set through the call's `response` handle, so no handler plugin. Inside a batch they merge like other headers.
- (agent) `retryLink`'s `delayMs(attempt, error)` gets the error, so a client can wait `retryAfter`; the default retry still skips typed errors.
- Why: Redis-backed distributed limits, token buckets and delay mode come from Effect; trpcdev adds only the tRPC error and headers.
- Lost: oRPC's Upstash and Cloudflare adapters (a `RateLimiterStore` layer would provide them); oRPC's per-request dedupe of the same limiter and key (leading duplicates in `.concat()` are dropped, [`middleware-dedupe.md`](./middleware-dedupe.md)).
- Lives in: `packages/trpcdev/src/server/ratelimit.ts`, `src/middleware/index.ts`, `src/client/links/basic.ts` (`delayMs`), `test/integration/ratelimit.test.ts`, `docs/procedures.md` (after the lifecycle helpers).
