# Publisher events can be tagged for some subscribers (agent)

- (agent) Built for the "tag targeting is later" in [`hibernation-state-and-subscriptions.md`](./hibernation-state-and-subscriptions.md), as a `Publisher` feature rather than a Cloudflare one: `publish(channel, data, { tags })` and `subscribe(channel, { lastEventId, tags })`. A subscriber gets an event when they share a tag; untagged events go to everyone, and untagged subscribers get only those.
- (agent) Tags travel inside the event (`{ '~trpc/tags': [...], data }`), wrapped by the `Posts.publish` accessor and unwrapped by `Posts.subscribe`. Backends store and replay it like any data, so the memory layer, the Redis and Postgres recipes and `hibernatingPublisher` filter by tag with no change to their shape, and replays after `lastEventId` respect tags too.
- (agent) The hibernating adapter keeps a parked subscription's tags in the socket attachment (`t`), so `publish` only sends to matching sockets after a wake.
- (agent) Tags are set on the server. The docs say to take them from `ctx` (or a [signed token](./hibernation-connection-tokens.md)), not from input, because a client choosing its own tags could read anyone's events.
- Compared: oRPC's `publishEvent(payload, { tags, targets, exclude })` on Durable Iterator objects. `targets` and `exclude` take socket objects, which only exist inside one object; tags work for every backend. Excluding the sender is left to the app (tag events with the audience instead).
- Why: the tag filter is a stream filter over the existing service, so Effect's `PubSub`, Redis pub/sub and the hibernating fan-out share one implementation.
- Lost: per-event filtering on the backend (Redis still sends tagged events to every process, which drops the ones its subscribers can't see); code that reads the service shape directly sees the envelope.
- Lives in: `packages/trpcdev/src/server/publisher.ts` (`PublishOptions`, `SubscribeOptions`, `isFor`), `src/cloudflare/publisher.ts`, `src/cloudflare/hibernation.ts` (`Parked.t`), `src/internal/hibernation.ts`, `test/integration/publisher.test.ts`, `test/integration/hibernation.test.ts`, `docs/subscriptions.md` (Tags), `docs/platforms.md`.
