# Vue bindings: one object of getters, `data` next to `promise` (agent)

- **`useQuery(factory, handle, options?)` returns one object** with getters: the controls React's tuple has (`isFetching`, `isPrevious`, `refetch()`, paging), plus `promise` and `data`. Same names as the React controls and the Svelte object, so the docs read the same across frameworks. Lost: TanStack vue-query's object of refs (`const { data } = useQuery()`). Getters track like a `reactive`, and `toRefs(result)` still works for destructuring.
- **`data` is the promise's value once it settles**, else `undefined`. Vue has no `use()`, so templates read `data` (`v-if="post.data"`); async `setup` under `<Suspense>` (and SSR) awaits `promise`. A handle from `ensure` / `fetch` types `data` as defined and falls back to the handle's `data` while a reset entry refetches. Lost: a `suspense()` method like vue-query's (`await post.promise` is the same thing).
- **The handle and options are `MaybeRefOrGetter`**: route data changes, so `() => props.post`. A sync `watch` reads the new query and switches the observer before anything renders the result.
- **Built on core's `QueryBinding`** ([query-binding](query-binding.md)): Vue supplies a version ref for `track` / `notify`, a sync `watch` that calls `syncUnsafe`, and the subscription in `onScopeDispose`. The observer, the settle hook, server reads and the getters live in core.
- **Server**: no subscription (SSR renders once and never unmounts); getters compute the result on read instead. `useIsFetching` is `0` on the server.
- **Plain TypeScript, no `.vue` files**: components are `defineComponent` setup functions with render functions, so `tsc` (TypeScript 7) type-checks the package and `vp pack` builds it. `vue-tsc` would need TypeScript's JavaScript API, which 7 doesn't have.
- **Providing the client**: `app.use(QueryPlugin, { client })` (mounts in the browser until the app unmounts), or `QueryClientProvider` / `provideQueryClient` for one subtree. `HydrationBoundary` hydrates synchronously before its slot renders: Vue doesn't throw renders away, so React's split into render-time and commit-time writes isn't needed.
- **An experiment, not a package yet** (human: "their packages and their example apps should live in experimental like react router used to do"): `.experimental/vue/` holds `package/` (`@raf-query/experimental-vue`, private, `0.0.0`), `sample/` (`@examples/experimental-vue`) and the draft guide in `docs/`, which the site doesn't build. Its README lists the steps to make it real. Lost: an "Experimental" label on a published `@raf-query/vue` (tried first).
- Lint: `.oxlintrc.json` turns off React's hook and compiler rules for `.experimental/vue/package/src`.
- Lives in `.experimental/vue/package/src`; draft docs in `.experimental/vue/docs/vue.md`.
