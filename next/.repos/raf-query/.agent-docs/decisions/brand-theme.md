# Brand colors and logo (human asked, agent designed)

- Human: find a color theme for the shared UI package and the logo, inspired by tRPC (also theirs) and/or TanStack Query. Then (human): the first, colorful pass looked tacky, and issue status colors belong outside the brand.
- **Brand**: tRPC's blue → violet → TanStack Query's coral (`#3B8EEA`, `#7B5CFF`, `#FF4D6D`). The full gradient appears only in the logo. In the UI, violet is the shadcn `primary` and the focus ring, and that's all.
- **Neutrals** are near-gray with a trace of violet (hue 286, chroma ≤ 0.012). `muted`, `secondary` and `accent` are the same gray, so hovers, skeletons and secondary buttons stay neutral.
- **Status colors are not brand colors**: open is emerald, in progress is amber, closed is zinc, shown as a dot in an `outline` badge (`status-badge.tsx` in each app). Lost: brand-tinted badge variants and a gradient dot in the filter (tacky).
- **Logo**: a gradient tile (blue at top left, coral at bottom right) with a white "r" and a dot: render, and a request in flight. The file is `www/public/favicon.svg`, which the docs site and the root README both use. The example apps and the docs header use the same SVG as a string in `examples/.shared/kit/src/lib/logo.ts`, through `<Logo>` and a data-URL favicon, because Next and Vite import static files differently. Keep the two the same. `www/public/og.png` shows the logo too: re-render it if the logo changes. Lost: the docs site's monochrome three-bar mark (looks like a generic "align left" icon).
- **Dark mode**: tokens use `light-dark()` and follow `color-scheme`. A `dark` or `light` class on `<html>` picks the theme, and without either the page follows the system setting (the `dark` variant in `globals.css` covers both cases). Apps wrap with `@examples/kit`’s `ThemeProvider` (`next-themes`) so vanilla shadcn `Toaster` can read the theme; example apps leave the choice at system. The docs site's switcher (`www/src/components/theme-toggle.tsx`) uses `next-themes` for System / Light / Dark and always sets one of the two classes, because its code-block styles and the demo devtools read `.dark`. In System mode it follows OS changes live.
- **Devtools** (`packages/react/src/devtools-panel.tsx`): violet accent and selected row, and the toggle's dot is the brand gradient. Query status colors stay semantic.
