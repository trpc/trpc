# Docs samples compile in workspace packages in `www/samples` (human)

- **Two sample apps, each a package** (human: "an actual thing with package.json inside of www/", "one for nextjs and one for tanstack"): `www/samples/tanstack-start` (`@samples/tanstack-start`) and `www/samples/nextjs` (`@samples/nextjs`). `www` lists each as a `workspace:*` devDependency. Lost: `examples/.shared/*` as the home (the human's first idea), since only the docs use these apps and `examples/` holds runnable demos.
- **One TanStack Start app for every TanStack sample** (agent): the quick start, the TanStack Start page and the guides share `tanstack-start`, so its `router.tsx`, `routes/__root.tsx` and `queries.ts` are each one file. The quick start shows the same router as the TanStack Start page, and its factories are the `todos` region of `queries.ts`, which wraps the region's own imports, so the file has a second import from `@raf-query/react` and `./api.ts`.
- **Each app declares what its blocks import** (agent): blocks compile with the app as Twoslash's `vfsRoot`, so imports resolve from the app's `node_modules`. A library a block imports goes in that app's `package.json`, not `www`'s.
- **A block's file is a path from `www/samples`** (agent): `tanstack-start/src/routes/posts.$slug.tsx`, in the `sample` fence and in the hidden `// @filename` that `build/snippets.ts` writes from it. `build/markdown.ts` picks the app from it and rewrites it to the path in the app. Inline blocks have no app (see [docs-sample-fences.md](./docs-sample-fences.md)).
- **Typecheck is each package's own `tsc`** (agent): the root `pnpm typecheck` filters `./www/samples/*`, which replaced `build/typecheck-examples.ts`. Each app has a standalone `tsconfig.json` (no shared base) with `~/*` → `./src/*`.
- **The Effect pages have their own app, `tanstack-start-effect`** (agent): the issue tracker of "Using Effect", with an in-memory `IssueApiLive`. A third app keeps Effect out of `tanstack-start`, which the quick start shows ("Using raf-query must not require knowing Effect"). The Effect pages' blocks are its files: "The whole picture" includes its routes and modules, the rest are in its `src/docs/`.
- **The homepage's hero is `tanstack-start`'s `blog.$slug.tsx`** (human: no bespoke app for it): the hero's post page `ensure`s both queries, while the walkthrough below it and the guides show `posts.$slug.tsx`, which `prefetch`es the comments. `Route.useLoaderData()` is typed from the registered route of the same id, so the hero is a route of its own id. Lost: a fourth app, `tanstack-start-home`, whose `/posts/$slug` was the hero's (seven files and a knip exception for one sample).
- **`settings.tsx` is a placeholder route** (agent): pages write their own versions in `src/docs/`, and the route tree needs the route to exist. `posts.tsx` is the url-state page's route, `posts.$slug.tsx` the post route the home page's walkthrough, the TanStack Start page and the guides show, and `blog.$slug.tsx` the hero's.
