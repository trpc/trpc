# `@examples/kit` holds the apps' shared markup, not their data code (human asked, agent designed)

- Human: move the shared components into kit, "just not anything that uses useQuery" or any actual factories, "so people can still read the example projects in isolation".
- **Kit** (`examples/.shared/kit/src/components`) holds the markup that is the same in all four issue tracker apps: `status-badge` (`StatusBadge`, `StatusDot`, `statusLabel`), `status-menu` (`StatusMenu`), `comments` (`CommentItem`, `CommentComposer`, the skeletons), `user` (`AssigneeCardView`, `AssigneeCardSkeleton`), `issue-list` (`IssueRow`, `issueRowClassName`, `IssueListSummary`, `NoIssues`, the skeletons), `settings` (`SettingsControls`), `app-header` (`AppHeader`), `loader-verb` (`LoaderVerbHint`; `lib/loader-verb` has `withLoaderVerb`), `issue-page` (`IssueBodySkeleton`, `StatusSkeleton`). Each takes plain values and callbacks. Its types come from `@examples/db/types`; the Effect app's `~/rpc.ts` types have the same shape, so it passes them as-is.
- **Each app** keeps everything a reader comes for: query factories, every `useQuery` / `useQueryClient` / `invalidate` / `prefetch`, loaders and server components, API and RPC calls, `useOptimistic` / `useActionState` / transitions around saves, cookie settings (`settings.ts`, `applyStaleTime`, Reset), and its router's `Link`. A kit view is rendered by the app component that owns the data, e.g. `StatusSelect` (optimistic save) renders `StatusMenu`, and the app's row `Link` wraps `IssueRow`.
- **Left in the apps**: `edit-title` / `edit-body` (the input's blur and Enter / Escape handlers submit the form and roll back the optimistic value, so they belong with the save), `status-filter` and `IssueNav` (all router links), the issue page's layout (it is where the Suspense boundaries are placed), and the one-line not-found and filter-skeleton markup.
- Kit components with event handlers or hooks are `"use client"`, like `@examples/ui`'s. Next.js server pages render kit skeletons, and without the directive their whole tree went into the RSC payload instead of a client reference.
- Lost: one app's copy of everything (each read alone, with nothing to jump to); a kit that also wraps data hooks (a reader of one app could no longer see its raf-query code).
