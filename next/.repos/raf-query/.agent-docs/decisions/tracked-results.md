# Tracked results live in core (human)

- **Tracked results live in core, as in TanStack** (human, 2026-10-12). `@raf-query/core`'s `QueryObserver` (`observer.ts`) has the mechanisms of query-core's `QueryObserver`: it builds the reader's result (the controls plus `promise`), owns `whilePending: "previous"` (like TanStack's placeholder data) and `refetchInterval`, and `updateResult` notifies only when a tracked prop changed (`trackedProps`, `trackResult` Proxy, `trackProp`; nothing tracked → notify on every change). `useQuery` mirrors `useBaseQuery`: observer in `useState` (with stable `subscribe` / `getSnapshot` closures over it), `getOptimisticResultUnsafe` in render, `useSyncExternalStore` on `subscribeUnsafe`, `setOptionsUnsafe` in an effect, `trackProp(observer, "promise")` (tuple reads are invisible), return `trackResult(observer, result)`. The per-listener preferences type passed to `Query.subscribeUnsafe` is `SubscribeOptions`.
