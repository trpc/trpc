# Two packages, React-agnostic core

- `@raf-query/core` (framework-agnostic, mirrors `@tanstack/query-core`) and `@raf-query/react` (bindings, re-exports core — apps install only this).
- **Core holds the Promise `QueryClient` too** (agent, superseding "core is Effect-only": the human allowed core to expose only Effect APIs while React was its only consumer). With Svelte and Vue bindings, `QueryClient`, `dehydrate(client)` / `hydrate(client)`, `allKeyed` (`src/client.ts`, `src/all-keyed.ts`) and what every binding's `useQuery` shares (`src/controls.ts`: `QueryControls`, `UseQueryOptions`, `promiseControls`, `resultThenable`) live in core, so each binding depends on core alone. Bindings re-export core. The Effect cache is still the engine: `QueryCache` verbs are Effects with exact types, and sync access during render follows Effect's `*Unsafe` naming (`getQueryUnsafe`, `Query.getUnsafe`, `Query.readUnsafe`, `Query.subscribeUnsafe`). Lost: a third package for the Promise client (one more lockstep package, and core alone isn't usable without Effect).
- Framework integrations are subpath exports of `@raf-query/react` (`/tanstack-router`), not separate packages. RSC and React Router need none: `QueryProvider` and `HydrationBoundary` are on the main entry.
- **Lockstep versions:** both packages always share a version and release together.
- `@raf-query/react` depends on `@raf-query/core` via `workspace:*`, which `pnpm pack` publishes as the exact lockstep version. `react` is a peer (`^19.2.0`).
- **`effect` is a required peer (`^4.0.0`) of both packages**, plus a `catalog:` devDependency for the workspace. A regular dependency, even a caret range, leaves deduping to the package manager, and a second Effect splits module-level state (service tags, default runtime) as well as adding size. Every install blurb lists `effect` next to the package (npm, pnpm, Yarn and Bun), so there is no manager-specific step. `vp pack` keeps peers external, so the dev copy isn't bundled. Lost: telling only Yarn users to add `effect` (human).
