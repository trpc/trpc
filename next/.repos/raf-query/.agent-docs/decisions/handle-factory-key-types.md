# Handles of same-signature factories don't mix (human asked; shape agent)

- Human: "make it so query handles on two different factories with the same signature can't be mixed up".
- **`queryOptions` / `infiniteQueryOptions` keep the key's literal type**: a `const TKey extends QueryKey` type parameter, stored as `key` in the returned bag. Unlike `error` / `services`, it is always there (`key: readonly unknown[]` for a key typed `QueryKey`): each optional member doubles the conditional branches in `QueryTypesOf`, and the first version, an intersection of optional parts behind a mapped `Flatten`, hovered as `InfiniteQueryOptions<Flatten<{ … } & { key: … }>>` in the docs (human: "looks ugly with the &"). A written bag without `key` still means any key (`KeyIn`). `QueryOptions.queryKey` is `KeyIn<TTypes>`. `QueryHandle<typeof postQuery>` and `QueryHandle<typeof draftQuery>` then differ through the phantom factory field whenever the keys' shapes differ.
- Reason: TypeScript compares function types structurally, so `typeof factory` alone can't tell two factories with the same input and data apart, and `useQuery(otherFactory, handle)` read the other factory's entry at runtime. Factories with the same key shape hit the same cache entries, so their handles still mix and that's harmless.
- Gaps, accepted: a factory whose return type is annotated `QueryOptions<{ data: Post }>`, a key built by a helper typed `QueryKey`, explicit type arguments (`infiniteQueryOptions<Page, number>(…)` defaults `TKey` to `QueryKey`), and generic makers whose keys differ only by a runtime string (`[endpoint.name, args]`).
- Lost: an opt-in `brand` (a `unique symbol` the app declares per factory; `queryOptions` can't mint one per call, TS1335) in PR #168; a required brand or `defineQuery` wrapper, which changes the factory shape the human picked in [public-api.md](./public-api.md); a runtime check in `useQuery` comparing keys (human: "I don't like the idea of runtime checks").
- Code: `packages/core/src/options.ts` (`KeyIn`, `QueryTypesOf`); tests: `packages/react/src/types.test.ts` ("keep handles of factories with the same signature apart"). Docs: `www/content/handles.md#typed-by-what-the-loader-did`.
