# The v11 docs

A copy of the [v11 docs](../../../../www/docs), which [trpc.io](https://trpc.io/docs) renders. The site serves it at `/docs`, for v11 users while v12 is experimental.

Don't edit these files: `www/build/old-docs-copy.ts` writes them. Change the docs in the repo root's `www/docs`, then run `pnpm --filter @trpc12/www old-docs:copy`.
