# The v9 docs

A copy of the [v9 docs](../../../../v11/www/versioned_docs/version-9.x), which [trpc.io](https://trpc.io/docs/v9) renders. The site serves it at `/v9/docs`, for v9 users while v12 is experimental.

Don't edit these files: `www/build/old-docs-copy.ts` writes them. Change the docs in `v11/www/versioned_docs/version-9.x`, then run `pnpm --filter @trpc12/www old-docs:copy`.
