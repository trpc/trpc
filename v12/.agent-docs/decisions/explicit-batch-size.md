# Batching needs an explicit size (human asked)

- Human, 2026-11-03: "in v12, when batching is turned on, a maximum batch size must be set explicitly. That covers the native handler's `batch` option and any other v12 entry point that batches calls".
- (agent) `batch` is `false | { maxItems: number }`, as `false` turns off `sse.pingInterval`: optional and off on `createFetchHandler` and `httpLink`, required on `createV11Handler`, which batched by default. `batch: true` and `{}` are type errors; plain JavaScript that passes them, or a `maxItems` that isn't a positive integer, gets a `TypeError` naming the option when the handler or link is made.
- (agent) Before: `batch: true` meant 20 calls on `createFetchHandler` and 10 on `httpLink`, and a missing `batch` meant 100 on `createV11Handler`, so a link could send batches its server refused without anyone having picked either number.
- (agent) The codemod writes `batch: { maxItems: 100 }` where v11 batched without a size, on the batch links and on `fetchRequestHandler` (which batched by default; before, the codemod left the server's batching off while turning the client's on), each with a note that says it added the value and why. v11's `maxItems` on a link and `maxBatchSize` on the handler move into `batch`; `allowBatching: false` is dropped, v12's default.
- Why: the size bounds the work one request starts, and a server and its links must agree on it; a default hid both.
- Lost: the `batch: true` shorthand. Every example and docs page spells out a size. The codemod's 100 on links is larger than `httpLink`'s old 10, so a migrated client sends fewer, larger requests.
- Open: with `batch: false`, `createV11Handler` still caps a `wsLink` message's array at 100 calls without the app choosing it, since v11's `wsLink` always sends arrays. Making that explicit needs a separate socket option ([`v11-interop-handler.md`](./v11-interop-handler.md)).
- Lives in: `packages/trpc/src/internal/batch.ts` (`batchMaxItems`), `src/server/handler/http-handler.ts`, `src/server/handler/fetch.ts`, `src/interop/handler/handler.ts`, `src/client/links/http/link.ts`, `packages/upgrade/src/transform.ts`, and the lint rule `tooling/oxlint-plugin/explicit-batch-size.ts` for examples and docs blocks; tests in `packages/trpc/src/server/handler/batch-size.test.ts`, `batch-size.test-d.ts` and `packages/upgrade/src/transform.test.ts`; docs in `www/v12/docs/client/links/http.md`, `www/v12/docs/migrations/from-v11/serve-v11-clients.md` and `www/v12/docs/migrations/from-v11/codemod.md`.
