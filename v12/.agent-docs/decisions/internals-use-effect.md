# Internal logic is written in Effect (human)

- Human, 2026-10-15 (decisions round 3, Q2): "all logic we write should use Effect except some public facing apis".
- Internals (control flow, concurrency, streams, resources, retries, timeouts, errors) are Effect: `Effect`, `Stream`, `Queue`, `Deferred`, `Scope`, `Fiber`. Not hand-rolled promise chains, `setTimeout` loops or callback bookkeeping.
- Public APIs can stay Promise- and callback-shaped where users expect them (`client.x.query()`, `for await`, `createContext`, TanStack's `mutationFn`), converting at the edge.
- Why: one model for interruption, cleanup and typed failures, and the parts compose with users' Effect code and layers.
- Lost: zero-dependency, framework-free internals.
- (agent) Moved in round 3: the file-bytes wait in `transformer/progressive-json/stream.ts` (a `Deferred` per byte stream and per target, waits as fibers instead of promise chains) and `httpLink`'s batching (`Queue`s instead of a hand-rolled async queue, each batch an `Effect` run as a fiber, scheduling with `Effect.sleep(0)`) and SSE reconnect loop (`Stream` plus `Effect.sleep` backoff, no `setTimeout`). The rest still moves as it's touched.
- (agent) Moved after round 3: `socketLink` holds its connection in an `RcRef` (shared by calls; `idleTimeout` is its idle time-to-live; a lost connection is invalidated), each call reads its own `Queue` inbox on a fiber with an `Effect.sleep` reconnect loop, and keep-alive is a fiber in the connection's scope. No `setTimeout`/`setInterval` or promise chains. `DeferredDecoder` is `makeDeferredDecoder()` returning effects; a value's head decodes on its own fiber so later chunks (file bytes) keep flowing, which also fixed files inside SSE subscription events hanging.
- (agent) Moved 2026-10-18: server WebSocket, raw socket and v11 `wsLink` sessions run on Effect's `Socket` through one runner, with a `FiberHandle` idle timer instead of `setTimeout`, and each socket or MessagePort call is a fiber in a `FiberMap` instead of an `async` function with an `AbortController` ([`websocket-sessions-on-effect-socket.md`](./websocket-sessions-on-effect-socket.md)).
- (agent) Moved 2026-10-18: the handler core builds the layer's services with the `ManagedRuntime`'s `contextEffect` instead of a cached `Promise`, and its `run` is `Effect.exit` of the call, with no Promise `run` at the edge ([`handler-core-on-effect.md`](./handler-core-on-effect.md)).
- (agent) Moved 2026-10-18: lazy routers load through one `Effect.cached` Effect per subtree instead of a memoized `Promise`, and `resolveProcedure` and `loadRouter` run Effects at the edge ([`lazy-routers-on-effect.md`](./lazy-routers-on-effect.md)). Since 2026-10-20, `resolveProcedure` is itself the Effect; only `loadRouter` runs one at the edge.
- (agent) Moved 2026-10-19: `localLink` runs the procedure on its own fiber inside `Effect.callback`, and the callback's signal (joined with the call's `signal` through `AbortSignal.any`) is the procedure's `signal`. Interrupting an Effect client's call now aborts it; before, a call without `signal` got a fresh `AbortController`'s, which never aborted. It aborts only on interruption, so a streamed output read after the call returns isn't cut. Test: `client/links/links.test.ts` ("interrupting a localLink call").
- (agent) Moved 2026-10-19: a socket link (`wsLink`, `experimental_socketLink`, `experimental_messagePortLink`) owns one `Scope` that holds its `RcRef` connection and the fibers it starts outside a call's own: dropping a lost or retired connection (`Effect.forkIn(…, { startImmediately: true })`, since a connection's fiber can't close the scope it runs in) and a call whose output still streams after it returns. These were bare `Effect.runFork`s on the default runtime and `Effect.forkDetach`es; they now inherit the caller's services and are tracked. Handling a message, losing and retiring a connection are Effects instead of functions with side effects called from `Effect.sync`. The scope stays open for the link's life: `close()` resets the connection and fails calls in flight, and the next call reconnects. `experimental_messagePortLink` adds its port listeners once through an `Effect.cached` Effect instead of a `let` flag, a `runSync`'d `PubSub` and a `Deferred.makeUnsafe`. Gzipped: `wsLink` +14 B, the message-port link +197 B.
- (agent) Moved 2026-10-19 (execution and procedures, [`effect-internal-patterns.md`](./effect-internal-patterns.md)): streamed outputs are one `Channel` pipeline ([`stream-item-validation.md`](./stream-item-validation.md)); Promise middleware's `next()` takes an interrupt-bound signal ([`effect-middleware-next.md`](./effect-middleware-next.md)); the lifecycle helpers run as Effect middleware ([`middleware.md`](./middleware.md)); actions read services through `runtimeServices` ([`actions-and-rsc.md`](./actions-and-rsc.md)); `emitEvents` runs each event's deferred chunks in a scoped `FiberSet`, which drops finished fibers, instead of an array of forked fibers joined at the end, and is an `Effect.fnUntraced`. Left as they are: the memory publisher's `seq` and `kept` and `experimental_byteStream`'s byte count are plain state changed in one synchronous step; `validate`/`validateThen` already run standard schemas synchronously when they can.
- (agent, 2026-10-20, [`effect-first-public-apis.md`](./effect-first-public-apis.md)) `t.call()`, actions and callables without a `signal` give the procedure one from `interruptSignal`, aborted when the call is interrupted (a resolver or middleware that interrupts it, a timeout around it), as `createRouterClient`'s `localLink` and HTTP calls already did. Before, it was a fresh `AbortController`'s, which never aborted. A given `signal` is passed through unchanged: aborting it interrupts the call.
- Lives in: all of `packages/trpc/src/`; the moved internals are `src/server/sockets/socket-session.ts`, `src/server/sockets/socket.ts`, `src/transformer/progressive-json/stream.ts`, `src/client/links/http.ts`, `src/client/links/socket.ts` and `src/client/links/events.ts`; tests in `packages/trpc/src/server/sockets/websockets.test.ts` (`close()` cases) and `packages/trpc/src/server/handler/files.test.ts` (files inside subscription events).
